# 小哈智电 iOS 原生客户端 (XiaohaBatteryTracker for iOS)

由 **王哥 & Google Antigravity** 联合打造，专为小哈 72V 锂电池（如 T71N/57Ah 等）开发的原生 iOS 客户端。

---

## 🌟 核心特性
- **4G 云端直连与主动唤醒**：内置小哈网关指令通信，支持 4G 主动下发硬件唤醒与实时数据拉取。
- **20 串电芯 4×5 矩阵遥测**：
  - 实时显示各单体电压 (mV)、单体剩余容量 (Ah)、单体 SOC (%)、单体微内阻 (mΩ) 与偏差偏移。
  - 自动标亮最高单体（青色）与最低单体（橙色）。
- **小哈 3D 官方同款电池立体图示**：待机/放电/充电发光电芯动态效果。
- **4G GPS 高精定位与门牌号**：独立换行展示省市区工业园门牌号与经纬度，点击一键复制。
- **一键寻车响铃**：远程向电池下发 4G 蜂鸣器指令。
- **灵活换机与凭证导入**：支持直接粘贴小哈小程序抓包 JSON 或 Token，群友一键导入即用。

## 📱 群友自签安装指南（IPA）

本项目已配置纯净免签打包流程，适合群友通过以下常用自签工具安装：

1. **AltStore / Sideloadly（电脑自签）**：
   - 将打包好的 `XiaohaBatteryTracker.ipa` 拖入 Sideloadly 或 AltStore。
   - 输入群友自己的 Apple ID 即可免费签名并安装至 iPhone（7天自动续期）。
2. **巨魔商店 TrollStore（永久免越狱安装）**：
   - 支持 iOS 14.0 - 16.6.1 / 17.0 的设备，直接在微信/QQ 中点击 IPA 用 TrollStore 打开，**永久免掉签**。
3. **企业证书 / 个人证书签名**：
   - 使用全能签、牛蛙助手、轻松签等工具，导入证书后签名安装即可。

## 🚀 云端自动打包 (.ipa)

本项目已内置 GitHub Actions 持续集成脚本（`.github/workflows/build_ipa.yml`）：
1. 在 GitHub 上新建一个仓库（公开或私有均可）。
2. 将本项目所有代码上传至该 GitHub 仓库。
3. 进入仓库的 **Actions** 页面，会自动触发 macOS 虚拟机云端编译。
4. 编译完成后，在构建任务下方的 **Artifacts** 区域即可直接下载编译生成的 `XiaohaBatteryTracker.ipa` 文件，直接发给群友！
